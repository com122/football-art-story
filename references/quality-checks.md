# 动画验收

verify-story.mjs 执行本任务生成的可信作品代码。它检查逐步轮廓、上色、全部选定标记完成、准确停留、最终停播和旧渲染器清除；不能代替真实观感与历史准确性。

## 实看

1. 一章由空白→部分连续轮廓→分层标记→完整人物，不扫描贴图。
2. 查看约 10%、45%、100% 帧，人物比例、姿势、脸部和肢体归属正确，皮肤头发衣服有区分。全身约定时包含发顶和双脚；允许裁切时自然出画，不能压缩人体。
3. 正常播放整章，完成后默认停一秒才切换，不能缺最后一遍。
4. 上色中段切换、倒退与重播，不能闪旧简笔人、下一完整图或旧媒介残留。
5. 生涯表真实队徽、日期口径、数字与数据收尾正确，长文字和多队内容不溢出。

| 画法 | 需要看到 | 常见失败 |
|---|---|---|
| 彩铅 | 短排线和真实颜色 | 噪点压住脸 |
| 石墨 | 分级明暗与脸部亮区 | 统一纯黑 |
| 水彩 | 半透明宽笔叠色 | 整图渐显冒充落笔 |
| 蜡笔 | 粗颗粒与完整色块 | 概括变残缺 |
| 钢笔 | 肤色留白与暗部排线 | 整人涂黑 |

概括与精画比较同一帧：必须对应原图的同一个动作、头部角度、手脚位置、五官位置与表情。概括用更少的衣褶、排线与明暗层次，眉眼鼻口仍可辨；精画增加分层明暗和内部纹理。两档应在正常观看尺寸明确不同，不能只改变墨色深浅。粗线简笔画还需检查轮廓有自然不规则感、笔画较少且粗，不是机械精确描边。不能把概括做成减少密度的全身排线或照片感脸部。

钢笔画像至少能认出球员身份，脸型、眉眼、鼻子、嘴、发型须保留。单纯把彩色排线变成黑墨不保证此项；失败时制作对应钢笔素材并用 artVariants 接入。彩色概括线条应有轻重和连续走向，不能只把精画照片加粗或把五官一起概括掉。

## 工作台

五种画法的界面选择与 canvas 的 artMedium 一致。各有效参数调节后重画所选章，单色隐藏饱和度。进度 100% 再倒退恢复中间态。保存／导入参数复现，非法字段和范围明确报错。

保存无面板 HTML 后独立打开，对照样式与时长、无工作台。检查控制台无未捕获错误。断网后备字体不影响绘制。

多媒介变动先跑完整绘制矩阵，再实看必要对照。通过后不重复，除非实现又变动。截图只辅助记录中间和完成态，不能冒充动画过程检查。

## 厚涂与分章

`verify-gouache.mjs` 使用真实Canvas比较开头、中段、终笔、停留和重播画面，检查全部宽笔、颜料轮廓、面部标记及跨章清空。共用背景但drawMs不同的章节也应按各自时长完成。

| 核对对象 | 观察依据 |
|---|---|
| 宽笔厚涂 | 源稿与完成帧都有成片色面、可见刷痕和自然肤色；不是只把细排线加粗 |
| 白底混色 | 大面积白色中少量红蓝随刷痕混杂；非两个角的纯色块 |
| 复杂姿势 | 回看原照片逐只确认手脚归属，修订后没有额外肢体，也没有误删本人的手 |
| 原队徽 | 真实版本、轮廓完整、无抠图灰边；未经过生成模型再发明 |
| 可读文字 | 在实际观看尺寸读正文和统计口径；浅底近黑字，照片说明不混入影片 |
| 数据／奖项 | 保留范围和核验日期，跨口径不合计，团队与个人奖区分，同一奖不重复 |
| 独立章节 | 每份HTML／MP4只含目标章，从空白到完整，停留后结束，不夹下一章 |

视频经ffprobe检查尺寸、帧率、帧数、时长；实际解码抽看中段和最后画面，再在播放器正常播放至少一段。ZIP内文件齐全且用相对链接。原片格式拆分不需要重生成素材。
