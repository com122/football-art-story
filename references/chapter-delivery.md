# 分章交付

用户说“像上次视频一样一章一章分开”时，可交付按顺序编号的独立MP4；同时保留独立HTML方便继续调整。已有原片则保持内容与当前速度，不再调用图像生成。默认只有HTML的请求不主动耗时渲染视频。

厚涂脚本使用 `football-gouache/1` 配置。旧素描 `schemaVersion:1` 继续旧编译器和已有项目导出方式；以下命令不声称能直接解析旧素描数据。

## 输出

```text
node <Skill>/scripts/export-gouache.mjs <story.json> <分章目录> --format html
node <Skill>/scripts/export-gouache.mjs <story.json> <分章目录> --format both --deps-root <node_modules> --ffmpeg <ffmpeg可执行文件> --ffprobe <ffprobe可执行文件>
python <Skill>/scripts/zip-chapters.py <分章目录> <目录外的归档.zip>
```

`--format mp4`只生成视频。`--chapter id`仅输出选中章。FFmpeg在PATH中时省略其路径；无PATH时通过参数传入。`--fps`默认30，可按需求选择。绘制终点和片段长度须落在帧边界，不匹配时明确报错，调整到相邻帧后再导出。

- 固定1920×1080，H.264、yuv420p、CRF18，默认无音轨；没有授权添加的配乐或旁白。
- 每章复用原几何，单独从空白开始、完整画完、停留后停止。不要把切页边界或下一章开头带入本章。
- 片段末尾包含完整画面。默认1秒停留在30fps中对应30帧；不要把最后一帧的时间戳误认为容器总时长。
- 名称为 `01-章节名.mp4`、同名HTML；另有 `index.html` 和 `chapters.json`。清单保存绘画时间、停留、帧数和规格。
- HTML内嵌该章所需几何，不用携带源图或其他章。总览页需要同目录的视频文件；ZIP连目录一起打包。

## 验证

导出器核对最后一帧全部笔触完成，并通过ffprobe检查分辨率、帧数、时长。另在播放器／浏览器实际播放至少一个代表片段，检查能解码、画面运动正确和结束后不自动接到下一章。对白底数据、脸部和复杂姿势抽看MP4中段与结尾；不能只查看源画稿。

重播独立HTML、拖动进度及回到开头，确认旧图层没有残留。比对分章清单的总时长与完整配置。最后打开ZIP目录检查文件数量和相对链接，不能把本机绝对路径当作接收者能访问的资源。

交付时提供可打开的预览目录、文件位置与ZIP，说明视频是否含音轨及用户需要的规格。不要只有“能做”或一个章节下拉框来替代已请求的独立文件。
